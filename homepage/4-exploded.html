Your own agent

Claude Code, Codex or OpenCode, the CLI you already use, signed in with your own subscription. No API keys, no account here.

A live preview of the real app

It sits next to the chat. Keep changing it by talking, or close the chat and just use it.

A real project underneath

Its own server and SQLite database, written and run by the agent, in a folder you can open.

A sandbox around it

Apps ask before reaching beyond it, and secrets never reach agents. Every change is a snapshot you can undo, data included.

This is all you see while you use it.

It changes the websites you use, too.

Ask about a page, or point at an element. The same agent hides, restyles or adds things, on one page or the whole site, and the change stays the next time you visit.

Each change gets its own switch. Bundle the ones you like into a mod to share.
