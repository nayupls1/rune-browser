A browser that builds what you ask for

Describe a small app and a coding agent builds it, runs it and keeps it in a tab. Point at a website and it changes that too. All on your own Claude Code, Codex or OpenCode login.

Download for free View on GitHub

For the small tools you never got round to building, and the sites you wish worked differently.

  • Describe an app, get a real one

    The agent writes a real project with its own server and SQLite database, runs it in a sandbox and shows it in a live preview next to the chat. Keep changing it by talking, or close the chat and just use it.

  • Change the websites you use

    Ask about a page or point at an element, and the agent hides, restyles or adds things, for that page or the whole site. Each change gets its own switch. Bundle them into a mod to share.

  • Your own agents and logins

    Claude Code, Codex and OpenCode, the CLIs you already use, signed in with your own subscription. No API keys, and no account here.

  • Safe, and nothing is lost

    Apps run in a sandbox and ask before reaching beyond it. Secrets never reach agents. Every change is a snapshot you can undo, data included.

Get Rune Browser

Install it, sign in to Claude Code, Codex or OpenCode once, and ask for your first app. It updates itself from there.
